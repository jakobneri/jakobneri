## 🛰️ Homelab & UniFi

My network is my playground — full **Ubiquiti UniFi** stack, everything segmented,
monitored and automated.

| Layer | What's running |
| :--- | :--- |
| 🧠 **Controller** | UniFi Network Application — central config, alerts & firmware |
| 🔀 **Routing** | UniFi Gateway with VLANs for IoT, Guest, Lab & Trusted |
| 🔌 **Switching** | UniFi PoE switches feeding APs, cameras & lab gear |
| 📶 **WiFi** | UniFi Access Points with per-VLAN SSIDs and fast roaming |
| 🐳 **Services** | Docker containers for self-hosted tools, monitoring & backups |

> **Why?** Because nothing teaches networking, DNS and firewall rules faster
> than breaking your own internet at 2am and having to fix it. 🙃
